# whatevercc.rs

Микро-сайт со статьями на [VitePress](https://vitepress.dev), публикуется на GitHub Pages,
домен `whatevercc.rs` (регистратор unlimited.rs).

## Локально

```bash
npm install
npm run docs:dev      # http://localhost:5173
npm run docs:build    # сборка в docs/.vitepress/dist
npm run docs:preview  # посмотреть собранное
```

## Новая статья

Создай `docs/posts/имя-статьи.md` и сразу его переводы `docs/en/posts/имя-статьи.md` и `docs/sr/posts/имя-статьи.md` (сербский латиницей). Без всех трёх языков PR не пройдёт проверку, подробности в `CLAUDE.md`.

Русская версия:

```markdown
---
title: Заголовок
date: 2026-09-17
---

Текст.
```

Список статей на главной собирается сам — только заголовки-ссылки.

- `title` — что показать в списке. Если его нет, возьмётся первый `# заголовок` из текста,
  а если и его нет — имя файла.
- `order` — необязательное число, ручной порядок в списке: 1 сверху. Статьи без `order` идут после них.
- `date` — нигде не отображается, задаёт порядок среди статей без `order` (новые сверху).
- `description` — необязательное, в списках не показывается, идёт в meta-теги для поиска.
- Дата и время последней правки внизу страницы берутся из времени коммита в git,
  во frontmatter их писать не нужно.

## Языки

Русский лежит в корне `docs/`, английский в `docs/en/`, сербский (латиница) в `docs/sr/`. Над английскими и сербскими страницами автоматически показывается сноска, что это AI-перевод.

```bash
npm run check:i18n   # все страницы есть на трёх языках и структура совпадает
```

## Ссылки на главной

Правятся руками в `docs/index.md`, секция «Ссылки» — обычный markdown-список.

## VS Code

Конфиг рабочего пространства лежит в `.vscode/` и приезжает вместе с репозиторием.
При первом открытии папки VS Code предложит поставить рекомендованные расширения — согласиться.

- `Ctrl+Shift+B` — запустить dev-сервер
- в .md набрать `post` + Tab — заготовка новой статьи
- `Ctrl+V` картинкой из буфера — файл сам ляжет в `images/` рядом со статьёй

## Деплой

Push в `main` → GitHub Actions собирает и публикует.

Разово в настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**,
затем **Settings → Pages → Custom domain** → `whatevercc.rs` → включить **Enforce HTTPS**.

Домен прописан в `docs/public/CNAME` (файл копируется в корень сборки — без него
GitHub Pages сбрасывает custom domain при каждом деплое).

### DNS на unlimited.rs (APOLO DNS Manager)

Для apex-домена `whatevercc.rs` — четыре A-записи:

```
@  A  185.199.108.153
@  A  185.199.109.153
@  A  185.199.110.153
@  A  185.199.111.153
```

Опционально AAAA (IPv6):

```
@  AAAA  2606:50c0:8000::153
@  AAAA  2606:50c0:8001::153
@  AAAA  2606:50c0:8002::153
@  AAAA  2606:50c0:8003::153
```

И `www` на GitHub:

```
www  CNAME  <твой-github-username>.github.io.
```

Проверка после распространения DNS:

```bash
nslookup whatevercc.rs
```
