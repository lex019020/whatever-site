# whatever-site

Сайт велоклуба Whatever (Нови-Сад, Сербия) на VitePress. Публикуется на GitHub Pages, домен `whatevercc.rs`.

## Команды

```bash
npm run docs:dev      # http://localhost:5173
npm run docs:build    # сборка в docs/.vitepress/dist
npm run lint          # markdownlint
npm run check:i18n    # все страницы есть на ru/en/sr и структура совпадает
python scripts/gestures.py   # пересобрать схемы жестов в docs/public/gestures
```

## Как работаем

- В `main` напрямую не пушим, только через pull request (squash merge). Ветки называем `claude/<что-делаем>`.
- На PR запускается проверка `Check` (markdownlint, проверка переводов, сборка). Деплой на Pages идёт сам после мержа в `main`.
- Перед PR прогоняй линтер и сборку локально.
- Если уже открыт небольшой PR с правками, новые правки докидываем в него, а не плодим отдельные PR. Перед этим проверяй, что PR ещё не смержен. После каждой такой правки дополняй описание PR.

## Статьи

- Лежат в `docs/posts/*.md` (переводы в `docs/en/posts/`, `docs/sr/posts/`), во frontmatter `title`, `description`, `order`, `date`. `order` задаёт порядок в списке на главной по важности (1 сверху), `date` - порядок среди статей без `order`.
- Ссылки между статьями - `/posts/<имя-файла>` без `.md`.
- Сейчас есть: `rules.md` (правила участия), `group-riding.md` (гайд по езде в группе), `etiquette.md` (вайб и этикет, пока заглушка).
- Картинки жестов - SVG из `scripts/gestures.py`. Руками SVG не правим, правим скрипт и пересобираем.

## Три языка - обязательно

- Каждая страница существует на русском (`docs/`), английском (`docs/en/`) и сербском латиницей (`docs/sr/`). Имена файлов одинаковые.
- Любая правка текста делается сразу во всех трёх языках, в том же PR. Переводы должны быть одинаково актуальными, «потом переведу» не бывает.
- У переводов совпадают `order`, `date`, заголовки и их уровни, картинки, таблицы, списки и внешние ссылки. Это проверяет `scripts/check-i18n.mjs`, и в CI он же проверяет, что изменённая страница изменена во всех языках.
- Метка PR `i18n-skip` отключает только проверку «изменено во всех языках» (например, опечатка в одном переводе). Структуру и наличие переводов она не отключает.
- Внутренние ссылки в переводах ведут на свою локаль: `/en/posts/...`, `/sr/posts/...`. Якоря - по переведённым заголовкам.
- Сербский - латиница, экавица, живой разговорный язык. Английский - такой же неформальный, как русский.
- Длинное тире «—» запрещено во всех языках.
- Над en/sr страницами тема сама показывает сноску «переведено AI, может быть неточно» со ссылкой на русский оригинал (`docs/.vitepress/theme/AiNotice.vue`). В тексты её не дописываем.

## Стиль текстов

- Живой человеческий язык, обращение на «ты», местами юмор. Без канцелярита и без ИИшных оборотов.
- Никаких длинных тире «—», вместо них « - ».
- Ведущего заезда называем «райд-лидер».
- Правила пишем с объяснением «почему», а не просто «нельзя».
- Правки в текстах предлагаем точечно и показываем итоговую формулировку, автор правит сам.
